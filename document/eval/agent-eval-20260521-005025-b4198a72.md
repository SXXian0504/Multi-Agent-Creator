## 6. 文本分析报告

### 稳定性

experiment 的任务成功率为 95.00%，baseline 为 95.00%。阶段成功率变化为 +0.08%。JSON 首次解析成功率和 Schema 通过率用于判断结构化输出是否稳定；如果 experiment 的 repair/retry 次数上升但最终成功率也上升，说明闭环把原本会失败的结构化输出转化为了可恢复流程。

### 质量

质量结论以 ReviewAgent 分数为准。标题、大纲、正文、配图计划和图片结果的均分与通过率见分阶段指标表。experiment 的优势应体现在低分阶段被重写或重规划后，最终交付分数和通过率提高；若某阶段均分下降，需要回看失败与重试案例中的具体主题和评审建议。

### 耗时

experiment 平均总耗时为 177833.80ms，baseline 为 181470.70ms。由于 experiment 增加 Review、repair、retry 和图片重规划，耗时通常会上升；可接受性需要结合质量分数、成功率和 fallback 降低情况判断。

### 图片工具

experiment 图片工具成功率为 92.21%，fallback 触发率为 31.58%，平均图片重规划次数为 2.05。若重规划次数增加但图片结果评分提高，说明 ImageAgent 的 observation -> replan 闭环有效；若 fallback 仍高，优先检查工具可用性和图表 prompt 质量。
